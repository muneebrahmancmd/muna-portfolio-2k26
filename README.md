I'm **Muneeb Rehman** — a creative developer, web designer, graphic designer and AI enthusiast from Pakistan. This is my latest portfolio: bold typography, smooth motion, and one idea I really like — instead of screenshots, the featured projects load as **live website previews right inside the page**, so you can see and click the real sites without leaving.

## ✨ Features

- 🖥️ **Live project previews** — featured work rendered as real iframes of the deployed sites, not static images
- ⚡ **Fast Vite build** — lightweight, instant dev server, tiny production output
- 🎞️ **Motion-first design** — animated loading screen, scattered-image sections and smooth section transitions
- 📱 **Responsive** — sized image sets (large / medium / small) so it looks right on every screen
- ✏️ **Content is data-driven** — projects and text live in simple files, easy to update

## 🛠️ Tech Stack

- **Vite** + **JavaScript (ES modules)**
- HTML partials + CSS for sections (About, Works, Projects, Contact)
- AVIF images, responsive assets, live iframe embeds

## 🚀 Run Locally

```bash
git clone https://github.com/muneebrahmancmd/muna-portfolio-2k26.git
cd muna-portfolio-2k26
npm install
npm run dev      # local dev server
npm run build    # production build in dist/
```

Node 20+ required.

## ✏️ Edit Content

- Featured live-preview projects and "More projects" list: `src/App/utils/data.js`
- Text sections: `src/App/partials/*.html`
- Images: `static/images`
