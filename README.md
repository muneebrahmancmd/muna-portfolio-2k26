# Muneeb Rehman — Portfolio

Portfolio of Muneeb Rehman: creative developer, web designer, graphic designer and AI enthusiast from Pakistan.

## Run

```bash
npm install
npm run dev      # local dev server
npm run build    # production build in dist/
```

Node 20+ required.

## Edit content

- Featured live-preview projects and "More projects" list: `src/App/utils/data.js`
- Text sections: `src/App/partials/*.html`
- Images: `static/images`
